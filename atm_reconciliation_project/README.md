# ATM Reconciliation Portal

This is a professional-grade Streamlit web app for reconciling ATM e-Journal logs with internal bank ledger records.

## Features

- Match by SEQ Number and Amount
- Detect Reversed, Failed, and Unmatched transactions
- Upload CSV files for journal and ledger
- Filter by SEQ and status
- KPI dashboard
- Download categorized reconciliation reports

## How to Run

```bash
pip install -r requirements.txt
streamlit run atm_reconciliation_app.py
```
